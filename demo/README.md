# Demo MicroPKI Sprint 8

Демонстрационный сценарий запускается из корня проекта:

```bash
python demo/demo.py
```

По умолчанию скрипт удаляет и заново создаёт каталог `demo/_work`. Это делает запуск идемпотентным: один и тот же demo можно выполнять несколько раз подряд без ручной очистки.

Что делает demo:

1. Создаёт рабочие директории и passphrase-файлы.
2. Инициализирует Root CA.
3. Выпускает Intermediate CA.
4. Выпускает server, client, code-signing и OCSP responder certificates.
5. Запускает repository server и OCSP responder.
6. Проверяет цепочку сертификата и OCSP-статус.
7. Запускает настоящий TLS server с сертификатом MicroPKI.
8. Показывает, что TLS без Root CA не проходит, а с Root CA проходит.
9. Подписывает файл и проверяет подпись.
10. Показывает отказ проверки после изменения подписанного файла.
11. Показывает блокировку wildcard SAN политикой безопасности.
12. Отзывает server certificate и показывает отказ revocation-aware проверки.
13. Проверяет audit hash chain и наличие сертификата в CT simulation log.
14. Останавливает фоновые серверы.

Чтобы сохранить сгенерированные файлы после запуска:

```bash
python demo/demo.py --keep
```
